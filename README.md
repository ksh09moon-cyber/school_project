# 나만의 스마트 옷장

## 웹 페이지

[웹 앱 열기](https://ksh09moon-cyber.github.io/school_project/)

## 코드 구성

- `index.html`, `dasda.html`: 앱 화면 구조와 스타일·스크립트 연결
- `css/app.css`: 앱 스타일
- `js/state.js`: 사용자, 옷장 데이터와 브라우저 저장소 상태
- `js/ui.js`: 알림과 확인 창
- `js/clothing-service.js`: 의류 분류, 이미지 분석, 날씨 입력 검증
- `js/recommendation-service.js`: 코디 평가와 추천 결과 생성
- `js/closet-view.js`: 화면 표시와 옷장 렌더링
- `js/app.js`: 폼, 버튼, 탭 이벤트 연결
